# Twitter Clone 🐦
A high-fidelity clone of the Twitter (X) web interface. This project focuses on complex layouts, including fixed sidebars, a scrollable main feed, and the "What’s Happening" sidebar.

## 🚀 Live Demo
[View the Live Project Here](https://astoriaking15.github.io/twitter-clone/)

## ✨ Features
- **Responsive Layout:** Works on Desktop and Tablets.
- **Sticky Navigation:** Left sidebar remains fixed while scrolling the feed.
- **CSS Grid & Flexbox:** Used for precise alignment of icons and text.
- **Custom Fonts:** Integrated Google Fonts for that authentic Twitter look.

## 🛠️ Built With
- HTML5
- CSS3 (Vanilla)
- Assets (SVG Icons)
